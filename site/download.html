In the zip

adapter/ The adapter's firmware

For the Waveshare RP2040-Zero, with the controller cable soldered to it. Wiring

  1. Hold the board's BOOT button while plugging it into a computer.
  2. Copy the .uf2 file onto the drive that appears.
  3. The board restarts by itself, as the adapter.

psp/ The PSP application

For a PSP-1000 with custom firmware (tested with 6.60 PRO-C).

  1. Connect the PSP to your computer (Settings > USB Connection).
  2. Copy the zip's PSP folder onto the Memory Stick: it holds PSP/GAME/PSP2DC.
  3. PSP2DC is now under Game > Memory Stick.

dreamcast/ The companion's discs

For homebrew developers: not needed to play.

  1. Disc images (.cdi) for a GDEMU's card: a demo game, the library's test and its tutorial in seven steps.
  2. Each uses the PSP as a second screen. The tutorial

Then

Plug the adapter into a controller port and the PSP into the adapter, and start PSP2DC from the PSP's Game menu. Using it

The PSP application and the adapter's firmware must be of the same release. What's new: the release notes. Earlier versions: the release on GitHub. Or build both from source: Building.
